七个工具（详见 README）：

1. **更多 → 重启 DSH**——标题栏下拉，点击立即重启桌面应用（⚠ 会中断正在运行的任务）；另有「重载插件」热重载已安装插件代码，不打断会话。
2. **生成**——输入栏按钮，按最后一轮 AI 回复起草意向回复并填入输入框。
3. **优化**——输入栏按钮，把输入框中的提示词改写为对 AI 更易懂、更可执行的版本；生成/优化期间输入框自动锁定。
4. **输入历史**——输入框内按 ↑/↓ 翻阅本会话你发送过的历史消息（越过最新一条恢复原草稿）。
5. **资源控制**——右侧「开始」工具栏入口，在右栏打开类 VSCode 标签页：按 git 仓库分组浏览变更（分组默认折叠，点击展开；A/M/D/R 徽标）、查看文件 diff、勾选部分文件单笔提交、按仓库历史风格 AI 生成 commit message、提交后可推送。
6. **常用语**——输入框上方悬浮短语条，点击即插入到光标处；最多展示 5 条，在工具设置中编辑。
7. **工具设置**——系统设置 → 工具设置：每功能独立开关、常用语编辑、自定义模型覆盖、资源控制扫描根目录管理。

Host 侧诊断日志：`%TEMP%\dsh-tools-debug.log`；重启助手日志：`%TEMP%\dsh-tools-restart.log`。
