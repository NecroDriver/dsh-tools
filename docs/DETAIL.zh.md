八个工具（详见 README）：

1. **更多 → 重启 DSH**——标题栏下拉，点击立即重启桌面应用（⚠ 会中断正在运行的任务）；另有「重载插件」热重载已安装插件代码，不打断会话。
2. **生成**——输入栏按钮，按最后一轮 AI 回复起草意向回复并填入输入框。
3. **优化**——输入栏按钮，把输入框中的提示词改写为对 AI 更易懂、更可执行的版本；生成/优化期间输入框自动锁定。
4. **输入历史**——输入框内按 ↑/↓ 翻阅本会话你发送过的历史消息（越过最新一条恢复原草稿）。
5. **资源控制**——右侧「开始」工具栏入口，在右栏打开类 VSCode 标签页：只扫描当前工作区（切换会话自动跟随），按 git 仓库分组浏览变更（分组默认折叠，点击展开；A/M/D/R 徽标）、查看文件 diff（详情顶部可一键切换 横向并排 / 纵向逐行 比对，偏好自动记忆）、勾选部分文件单笔提交、按仓库历史风格 AI 生成 commit message、提交后可推送。面板标题行（刷新按钮旁）和每个分组右侧各有「更新代码」（`git pull --rebase --autostash` 保住本地未提交修改）与「更新数据库」（`pnpm prisma:generate` → `pnpm prisma:push`，无这两个脚本的仓库自动跳过）按钮——标题行按钮批量作用于全部仓库（批量进度与摘要在标题行下方以细行显示，空闲时隐藏），分组按钮只作用于该仓库。**撤销改动**（v0.8.0）：文件行悬停出现撤销小图标（单文件），提交栏有红色「撤销」按钮（撤销全部勾选）；确认弹层分两栏写明处置——修改/删除/重命名的文件从最近提交还原（含暂存区），新增文件（含已暂存）直接删除（不可恢复）；删除后留下的空目录一并清理（止于仓库根）。未跟踪目录按文件逐个列出（同 VSCode），不再折叠成一条目录记录。
6. **常用语**——输入卡片内、输入框正上方的短语条，点击即插入到光标处；最多展示 5 条，在工具设置中编辑。
7. **今日 Token 用量**——侧边栏左下角（账号行上方）的「今日」用量小条：一眼看到当日总用量，点击弹出明细（输入/输出/缓存读/缓存写占比条、近 7 天迷你柱状图（悬停即时显示日期/星期/当日总量/请求数）、请求数与活跃会话数）。Host 侧按计费级语义从会话日志增量聚合，30 秒缓存、点击/切回标签页/每 5 分钟刷新；侧边栏收起时缩为 32×32 图标按钮。
8. **工具设置**——系统设置 → 工具设置：每功能独立开关（含「新会话默认展开右侧栏」，默认开——新会话启动即展开右侧栏，启动时恢复出来的既有会话与你手动收起过的会话保持原状；启动恰好落在空白新会话上则照常展开）、常用语编辑、自定义模型覆盖、资源控制扫描根目录管理。

Host 侧诊断日志：`%TEMP%\dsh-tools-debug.log`；重启助手日志：`%TEMP%\dsh-tools-restart.log`。
