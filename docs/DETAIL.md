Eight tools (see README for details):

1. **More → Restart DSH** — titlebar dropdown restarts the desktop app immediately (⚠ running tasks are interrupted); also **Reload plugins** hot-reloads installed plugin code without interrupting sessions.
2. **Generate** — composer button drafting an intended reply from the last assistant message.
3. **Optimize** — composer button rewriting your prompt into a clearer, more executable version; the composer locks while generating/optimizing.
4. **Input history** — ArrowUp/ArrowDown in the composer cycles through your own sent messages.
5. **Source Control** — an entry in the right "Start" toolbar opens a VSCode-style tab in the right sidebar: scans only the current workspace (follows session switches automatically); git changes grouped per repository (groups start collapsed, click to expand; A/M/D/R badges), per-file diffs (a toggle above the diff switches side-by-side / unified, preference remembered), checked-subset partial commits, AI-generated commit messages following the repo's own style, and push. Both the panel's header row (beside the refresh button) and each group header offer **Update code** (`git pull --rebase --autostash`, keeps local uncommitted changes) and **Update database** (`pnpm prisma:generate` → `pnpm prisma:push`, repos without those scripts are skipped) — the header-row buttons batch over every repository (progress and summary appear in a slim note line under the header, hidden while idle), the group-header ones act on that repo only. **Process console** (v0.8.1): per-repo Update code / Update database run as interactive process sessions — a terminal-style console embeds inside the group (command-line header + exit-code status) and streams output live; while a command runs you can type stdin lines into its input box (Enter to send) or kill it with one click; a Prisma data-loss error surfaces a red "accept data loss and retry" action (re-runs with `-- --accept-data-loss`), a rebase conflict surfaces "abort this update" (`git rebase --abort`), plus a copy-output action. Batch runs walk every repo through the same sessions, marking failures without stopping. **Revert changes** (v0.8.0): a small undo icon appears on each file row when hovered (single file) plus a red "Revert" button in the commit bar (whole selection); a confirm dialog spells out the two fates — modified/deleted/renamed files are restored from HEAD (index included), added files (untracked or staged) are deleted outright — and newly created files that vanish after a revert also take their now-empty directories with them (never above the repo root). Untracked directories are listed file-by-file (like VSCode), not collapsed into one entry.
6. **Quick phrases** — a row of phrase pills inside the composer card, right above the input; clicking one inserts it at the caret. Up to five shown, editable in Tools settings.
7. **Today's token usage** — a compact chip at the sidebar's bottom-left (above the account row) showing the day's total token usage; clicking opens the details (input/output/cache-read/cache-write bars, a 7-day mini chart (hover a column for an instant tooltip: date, weekday, that day's total, request count), request and active-session counts). Aggregated Host-side from session logs with billing-grade semantics, incrementally, 30 s cache; refreshes on click/tab-visible/5 min; shrinks to a 32×32 icon when the sidebar is collapsed.
8. **Tools settings** — Settings → Tools: per-feature switches (including "Open the right sidebar on new sessions", on by default — new sessions start with the right sidebar expanded while an existing session restored at startup and sessions you collapsed keep their state), quick-phrase editor, custom model override, Source Control scan roots.

Host-side diagnostics: `%TEMP%\dsh-tools-debug.log`; restart helper log: `%TEMP%\dsh-tools-restart.log`.
